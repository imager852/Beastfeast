盤點系統設定（管理員）

  1. 在 GitHub 建立一個私人 (Private) 倉庫，例如 beastfeast-stock，放入 items.json（貨品清單）。
  2. 建立 Fine-grained token：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → 只選該私人倉庫 → Repository permissions → Contents: Read and write。
  3. 在下面填入 token 和員工登入密碼，按「生成設定」。
  4. 把生成的內容存成 stockcount/config.js（Beastfeast 倉庫）。

Token 只會在這個瀏覽器內用登入密碼加密，不會傳送到其他地方。所有員工共用同一個密碼。密碼越長越安全：4 位數字（例如 1234）只能擋住一般人，建議用 8 個字元以上、混合英文和數字。
